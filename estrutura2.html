Bem-vindo ao Html5

HTML (HyperText Markup Language) é a linguagem de marcação padrão usada para criar e estruturar páginas da web.
Ele funciona como o esqueleto de um site ao organizar textos, imagens e links para os navegadores.

Como Funciona o HTML

O HTML funciona por meio de tags (etiquetas), que são comandos escritos entre os sinais de menor e maior (< e >).
A maioria das tags possui uma abertura e um fechamento para indicar onde um elemento começa e termina.

Características

  • Tags (): Elementos delimitados por sinais de menor e maior que dizem ao navegador como exibir o conteúdo.
  • Hipertexto: Refere-se à capacidade de conectar diferentes páginas ou arquivos por meio de links (hiperlinks).
  • Estrutura básica: Funciona como o "esqueleto" do site, organizando o conteúdo antes de receber o design ou as interações.

Linguagem de Marcação:

Usa códigos chamados tags (como <h1> ou <p>) para indicar ao navegador o que é um título, um texto ou uma imagem.

Não é programação

Ele apenas organiza o conteúdo, não realiza lógica ou cálculos complexos.

O trio essencial

  • HTML (Estrutura): É o esqueleto. Define o conteúdo bruto e a organização da página.
  • Css (Estilo): Controla o estilo e o visual (cores, fontes, layouts - a aparência).
  • JavaScript (Comportamento Dinâmico): Adiciona interatividade e comportamento (animações, formulários dinâmicos, lógica de funcionamento).
